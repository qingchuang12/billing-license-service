## 如何新增文档

- 产品/架构类文档放在仓库根目录（`README.md` / `架构设计.md` / `业务流程.md`）；
- 运维/脚本类放在 `scripts/`（见其 `README.md`）；
- 临时整改、审计、排期类放在根目录 `plan.md`，不要污染产品文档。
