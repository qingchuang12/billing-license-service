## 如何新增文档

- 产品/架构类文档放在 `docs/`（`README.md` / `架构设计.md` / `业务流程.md`）；
- 运维/脚本类放在 `scripts/`（见其 `README.md`）；
- 当前任务与整改统一写入 `docs/plan.md`（唯一活动 plan，带版本号）；完成的 plan 移入 `docs/archive/`，不要污染产品文档。
