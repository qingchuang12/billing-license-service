## 如何新增文档

- 产品/架构类文档放在 `docs/`（`README.md` / `架构与业务流程设计.md` / `授权设计方案.md`）；
- 运维/脚本类放在 `scripts/`（见其 `README.md`）；
- 当前任务与整改统一写入**活动 plan** `docs/plan-<x.y>.md`（文件名带版本号，新建时版本号递增）；原则上只保留**一个**活动 plan，若确需并行（如新功能线 + 上线验证线），必须在本索引中登记两者分工与状态；完成的 plan **直接删除**（不建 `docs/archive/`、不留备份），历史结论从 `git log -- docs/` 追溯；
- 设计建议类文档必须在文首声明「设计建议 · 非实现现状」并给出与实现的偏离清单，避免与实现文档混淆。
