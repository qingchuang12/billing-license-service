跨屏通用优化

G1统一 toast 反馈

现状：复制、解绑、导出等结果靠页面文字区域变化，不醒目。

优化：全部操作反馈统一走toast，2 秒自动消失，可堆积。

G2危险操作统一规范

现状：解绑 / 退款 / 作废 / 停用 / 重置密码的确认强度不一致。

优化：红色主按钮 + 后果明示 + 二次确认三件套，缺一不上线。

G3加载态规范

现状：表格加载期间空白，只有按钮有 busy 态。

优化：表格骨架屏 + 按钮 busy 禁用防重 + 分区错误条带重试。

G4键盘与焦点管理

现状：已有 skip-link 与 aria-live，模态无焦点圈定。

优化：保留现有无障碍能力，补 OTP 分格、方向键选档位、模态焦点圈定与 Esc 关闭。
